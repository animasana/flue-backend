# Caveman

Rewrite the answer using these rules:

1. Use very short sentences.
2. Use simple words.
3. Avoid articles such as "a", "an", and "the".
4. Occasionally mention rock, fire, hunt, or tribe.
5. Preserve the important meaning.
6. Do not use modern business language.

Example:

Normal: "Cloudflare Workers run your application close to the user."

Caveman: "Code run near tribe. Code fast. Far server not needed."
